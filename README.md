# My_Mediscope
A group of possible models to train body vitals and body sounds to train , analyze and predict health conditions

MediScope - Health Monitoring & Condition Prediction Using ML
MediScope is a machine learning-based health monitoring system designed to analyze real-time vital signs like pulse (BPM), SpO₂, and body temperature to predict the user's health condition. The project incorporates a cleaned and expanded dataset of over 100,000 rows and uses supervised learning techniques for classification. Initially trained using decision trees for quick insights, the model is being extended with advanced algorithms inspired by the open-source VitalRPM project (by hammvdh), which includes logistic regression, random forests, and deep learning for improved accuracy. The backend is modular and designed to seamlessly integrate with hardware inputs like Arduino + sensors, and a custom UI.
